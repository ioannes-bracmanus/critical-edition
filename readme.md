**critical-edition**

* `critical-edition.sty` es un paquete "minimalista" que permite trabajar ediciones críticas, proveyendo a los usuarios de tres tipos de **footnotes** (`\footT`, testimonios; `\footA`, aparato crítico o de variantes; y `\footE`, explicaciones) y un **entorno numerado** (`\bnum` y `\enum` como llave global, que entre sí tendrán: `\nstart` y `\nend` para prosa o textos poéticos extensos que precisen del mayor espacio posible de la página; o `\postart` y `\poend` para textos poéticos que se ubicarán más centrados respecto a la página).
